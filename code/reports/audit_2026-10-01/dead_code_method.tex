

\textbf{Mechanical inventory.} \texttt{b6\_tools/inventory.py} (standard
library only) parses the 28 Python files (\texttt{code/*.py},
\texttt{code/reports/*.py}) with \texttt{ast} and records every
\texttt{FunctionDef}/\texttt{AsyncFunctionDef}/\texttt{ClassDef} with
its decorators (\texttt{njit}, \texttt{staticmethod},
\texttt{pytest.mark.*}), its enclosing class, and its line range:
\textbf{611 definitions} (324 in non-test modules, 287 in
\texttt{test\_*.py}). It then records every \texttt{ast.Name} and
\texttt{ast.Attribute} reference in all files with file:line, every
string constant that contains a definition name (string-only hits are
reported separately and never counted as callers), and every
word-boundary hit in the five \texttt{*.sh} drivers (comments stripped).
A reference inside the definition\textquotesingle s own line range is a
self-reference, not a caller. The raw result, one row per definition
with caller counts by class (\texttt{n\_refs\_nontest},
\texttt{n\_refs\_test}, \texttt{n\_refs\_shell}, \texttt{n\_self\_refs},
\texttt{n\_string\_hits}) and the first twelve call sites, is
\texttt{B6\_inventory.csv} next to this file (a
\texttt{class}/\texttt{note} column has been appended after the manual
pass).
